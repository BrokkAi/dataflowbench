This command automatically detects Java/Kotlin build systems, builds the project, and analyzes it

Arguments:
  source-path  - Path to the project sources (default: current directory)

Use --project-model to scan a pre-compiled project model instead of compiling from sources.

Usage:
  opentaint scan [source-path] [flags]

Flags:
      --code-flow-limit int                      Maximum number of code flows to include in the report (0 = unlimited)
      --dataflow-approximations stringArray      Dataflow approximation class directory or Java source directory (repeatable)
      --dry-run                                  Validate inputs and show what would run without compiling or scanning
  -h, --help                                     help for scan
      --log-file string                          Path to the log file (default: <cache-dir>/logs/<timestamp>.log)
      --max-memory string                        Maximum memory for the analyzer (e.g., 1024m, 8G, 81920k, 83886080) (default "8G")
  -o, --output string                            Path to the SARIF-report output file
      --passthrough-approximations stringArray   Pass-through approximation YAML file or directory (repeatable)
      --project-model string                     Path to a pre-compiled project model (skips compilation)
      --recompile                                Force recompilation even if a cached project model exists
      --rule-id stringArray                      Filter active rules by ID (repeatable)
      --ruleset builtin                          YAML rules file, directory of YAML rules files ending in .yml or .yaml, or builtin to scan with built-in rules (default [builtin])
      --semgrep-compatibility-sarif              Use Semgrep compatible ruleId (default true)
      --severity stringArray                     Report findings only from rules matching the supplied severity level. By default only warning and error rules are run (note, warning, error) (default [warning,error])
  -t, --timeout duration                         Timeout for analysis (default 15m0s)
      --track-external-methods                   Write external-method coverage files next to the SARIF report

Global Flags:
      --color string       Color mode (auto, always, never) (default "auto")
      --config string      Path to a config file
  -d, --debug              Enable debug output (stream JAR subprocess output, show debug-only fields)
      --java-version int   Java version to use for running analyzer (default 21)
  -q, --quiet              Suppress interactive UI elements (spinners, progress bars) and JAR streaming
      --skip-verify        Skip SHA256 checksum verification of downloaded artifacts
