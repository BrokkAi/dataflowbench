# Composed Swift native diagnostic lane

This version composes resolver-backed Foundation endpoints, append and String/Data
heuristic guards, and the existing pinned SSA, numeric-scalar and keyed-content
library patches. It is the `adapter-composed-v1` lane, not a shipped vendor-native
model. Historical tool-native reports and denominators do not change.

The serial runner binds all 12 native canonical cases to exact retained database
files and source archives before running new queries. The final initialized-key
coverage query is mandatory for persistence. A separate structural scope query
provides its expected scope inventory. No new UserDefaults behavior is introduced.

Observation collection is independent of fixture expectations. Valid unexpected
flows on negatives remain reached observations; absence on positives remains
not-reached when endpoints are present. Every raw row is retained, including
flows outside the canonical anchors. Wrong-profile or malformed rows are evidence
errors. Missing endpoints cannot establish a clean negative. Qualification tests
may compare observations with expected behavior, but cannot rewrite observations.

The 12-case selection is preregistered. Failed or unattempted cases remain in the
result set as runner errors with their records. Uncertain process cleanup stops
further work. All runs use fresh output paths and preserve previous artifacts.
The portable replay validates artifact/query hashes, canonical archived bytes,
historical extraction witnesses and logs, exact query/decode argv, and explicit
adapter-lane attribution before normalization.

This is a new analysis of retained datasets, not a fresh extraction or benchmark
performance run. The canonical 60-second/512-MiB budget remains unchanged. The
60-second/2048-MiB diagnostic query budget and unproven aggregate containment
keep definitive raw observations inconclusive. Typed persistence incompleteness
survives independently of findings and resource status. No scored activation,
freeze, release, or canonical opaque registration is established.

Run `python3 scripts/test-swift-native-composed.py` and
`python3 scripts/verify-swift-native-composed.py` to replay the portable checks.

## Retained composition observations

The first attempt completed all 12 cases. The six positives reached their
canonical sinks and the six negatives did not, with exact endpoints present.
Both persistence cases reported `AdmittedClosedScope` at scope 3, matching the
separate structural inventory. These are observed results, not assumptions used
by collection. All 12 normalized rows are inconclusive with the explicit
resource-contract mismatch and unavailable aggregate qualification.
