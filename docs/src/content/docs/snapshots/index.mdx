import { snapshots } from '../../../data/snapshots';

A snapshot is an immutable freeze: corrected evidence creates a **new**
snapshot with a new release name and digests, and old snapshots remain
browsable for audit. The stable pointer
[`/current`](/current) always resolves to the current snapshot.

        </td>
      </tr>
