Each scored template is a balanced pair: one positive case (the flow exists)
and one minimally different negative case (it does not). A sound-and-precise
analyzer shows `reached` / `not-reached`. `inconclusive` preserves incomplete
proof, while `unsupported` records a declared capability boundary.

The unchanged 852-case population was measured through all 82 fresh reports.
The four changed cells are visible in the Java rows:

- Bifrost `anonymous-implementation`: both cells moved from `inconclusive`;
  the positive is now `reached` and the negative `not-reached`.
- OpenTaint `callback-registration` positive: `not-reached` → `reached`.
- OpenTaint `map-iteration` positive: `not-reached` → `reached`.

`chal-*` and the unprefixed kernel templates are benchmark-controlled kernels.
`model-*` templates are the benchmark-controlled modeling matrix.
`native-*` templates are the tool-native probe set, where the tool decides
with nothing supplied by us. The **Model profile** column separates these
populations; a native `unsupported` / `unsupported` row is a declared decline,
not two wrong answers.
