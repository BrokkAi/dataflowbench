import ScorecardSummary from '../../../../components/ScorecardSummary.astro';
import DimensionRates from '../../../../components/DimensionRates.astro';
import { snapshots } from '../../../../data/snapshots';

export const snapshot = snapshots.find((s) => s.version === 'v0.7.0');

Each scorecard is one frozen report: one analyzer, one track, one score
dimension, one model profile. Scorecards are independent result populations
and are never combined into a leaderboard. `TPR`/`FPR` are macro-averages
over templates, then semantic dimensions; incomplete outcomes are coverage,
never negatives.

This snapshot's scorecards span two model profiles, and every card below
states its own. A `benchmark-controlled` card and a `tool-native` card answer
different questions on different populations: the first measures the engine
with the benchmark's model supplied, the second measures the product with
nothing supplied. **Do not read them against each other.**

Eight analyzers appear here, and they do not cover the same languages. The
number of cards an analyzer has is its coverage in this freeze, not its
quality: Bifrost has a card for every kernel, Pysa has three. Comparing card
counts is comparing footprints.

**The version each card states is the version that produced it.** Five
analyzers re-ran for this release — Bifrost on v0.10.9, Semgrep CE on 1.176.0,
Joern on 4.0.617, OpenTaint on `analyzer/2026.09.03.9752bd2`, and the eleven
CodeQL kernel populations on the unchanged CLI 2.26.4 under the endpoint probe
(A30). The other eighteen cards are the reports v0.6.1 bound, carried over
byte-identical and re-digested into this manifest: CodeQL's six modeling and
tool-native populations, Infer's five, FlowDroid's four, and Pysa's three.

Two of the re-runs are worth reading against each other on this page. Semgrep
CE, Joern and OpenTaint each moved a pin and **reproduced every committed
outcome exactly**, so their cards below are numerically identical to v0.6.1's
under a new build identity — which is what a currency bump is supposed to look
like, and is only knowable because the slices were actually re-run. CodeQL's
kernel cards, by contrast, moved without the engine moving at all: the pin is
the same 2.26.4, and five `not-reached` results became `inconclusive` because
A30 stopped scoring a negative whose source endpoint the retained SARIF shows
was never observed.
