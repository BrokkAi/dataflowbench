## Qualification and acceptance

The original settled-timing requirements were not met by these diagnostic continuations.
Contention, missing host observations, partial analysis and retrospective acceptance remain
explicit. These are distributions across different cases and analyzer-specific populations,
not repeated-trial distributions, a matched speed comparison or a cross-release performance claim.
The existing A20 phase boundary is preserved for FlowDroid modeling: its analyzer phase is
shown, with compilation and DEX materialization excluded; the evidence retains all phases.

The Joern Swift wording reconciliation changes only the exact diagnostic wording of 12
unsupported decisions to match their released reasons. It accepts 96 retained invocation costs,
including four partial invocations with no query phase. All 96 normalized outcomes remain
inconclusive; no successful-analysis latency is certified. The original controller failure is
preserved, as are the retrospective scratch-accounting limitation and source provenance.

Joern Rust remains quarantined for a substantive result mismatch and contributes no accepted
cold costs. CodeQL Swift is blocked by the missing exact pinned custom extractor and is paused;
this publication launches no recovery or analyzer run.
