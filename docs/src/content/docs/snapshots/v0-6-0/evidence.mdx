import CaseEvidence from '../../../../components/CaseEvidence.astro';

export const snapshot = snapshots.find((s) => s.version === 'v0.6.0');

Every result links its retained raw-evidence artifact (SARIF or analyzer
output), digest-bound in the
<a href={evidenceUrl(snapshot, snapshot.results.manifest.path)}>freeze manifest</a>.
That includes the runs that decide nothing: a `tool-native` scorecard whose
twelve results are all `unsupported` still retains its evidence and its
witnessed run identity.

Every invoked case in this freeze also retains a phase-timing sidecar beside
its raw evidence, and every run retains an environment stamp. Those are
additive metadata read only by the
[latency page](/dataflowbench/snapshots/v0-6-0/latency/); no correctness
outcome on this page was derived from, or conditioned on, a timing value.

{snapshot.results.scorecards.map((scorecard) =>

    )),
  ),
)}
