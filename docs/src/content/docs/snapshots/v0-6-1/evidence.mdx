import CaseEvidence from '../../../../components/CaseEvidence.astro';
import { snapshots, evidenceUrl } from '../../../../data/snapshots';

export const snapshot = snapshots.find((s) => s.version === 'v0.6.1');

Every result links its retained raw-evidence artifact (SARIF or analyzer
output), digest-bound in the
<a href={evidenceUrl(snapshot, snapshot.results.manifest.path)}>freeze manifest</a>.
That includes the runs that decide nothing: a `tool-native` scorecard whose
twelve results are all `unsupported` still retains its evidence and its
witnessed run identity.

Bifrost's artifacts here are **new bytes**, produced by the v0.10.8 re-run;
every other analyzer's are the artifacts v0.6.0 retained, carried into this
manifest unchanged and re-verified against their recorded digests. Nothing was
re-run to make a number agree with another number.

The Go `array-element` pair is worth opening: its raw evidence carries the
diagnostic behind the regression this release publishes — *"taint discovery is
incomplete: procedure value-flow snapshot … is unsupported (`index_memory`)"* —
which is why those two cells read `inconclusive` rather than being scored as
misses.

Every invoked case in this freeze also retains a phase-timing sidecar beside
its raw evidence, and every run retains an environment stamp. Those are
additive metadata read only by the
[latency page](/snapshots/v0-6-1/latency/); no correctness
outcome on this page was derived from, or conditioned on, a timing value.
