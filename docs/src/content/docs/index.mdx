## What DataFlowBench measures

DataFlowBench evaluates whether static analyzers correctly decide **semantic
data-flow questions**: does a value from a source reach a sink, and just as
importantly, does the analyzer stay quiet when it should? Cases are balanced
positive/negative pairs of language-neutral **semantic templates** (aliasing,
kills, call context, branch joins, exception paths, …) instantiated per
language, and analyzers run them under a **benchmark-controlled** model
profile so the engines — not the shipped model packs — are compared.

Five properties keep the results honest:

- **No combined leaderboard.** Taint, value-flow, typestate, witness quality,
  and performance are independent scorecards.
- **Model profiles never pool.** `benchmark-controlled` and `tool-native`
  results stay separate.
- **Incomplete is not negative.** `inconclusive`, `unsupported`, and
  `runner-error` outcomes are capability coverage, never counted as clean
  negatives.
- **Explicit denominators.** Every rate is an exact fraction; headline rates
  are macro-averages over templates, then semantic dimensions.
- **Frozen evidence.** Numbers are generated from a validated, digest-bound
  freeze manifest; CI rejects stale pages.
