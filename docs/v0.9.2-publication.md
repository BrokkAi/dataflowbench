Publication uses the completed v0.15.1 matrix and never launches an analyzer.
The explicit publication instruction is retained in
`reports/releases/v0.9.2/publication-approval-20261107.json`.

## Input boundary

PR 299 merged the reviewed evidence into main at
`44b342c5a436fc8c6956c1772b503babd8ff5b8d`. The portable publication-input PR
adds path-only normalized projections, exact raw copies, the mandatory Joern
qualification sidecar, lossless compressed LFS delivery, and verification
helpers. It must merge before a freeze records its evidence revision.

```sh
python3 -B scripts/v092_publication_evidence.py hydrate --root .
python3 -B scripts/v092_publication_evidence.py verify --root .
```

Hydration restores only the manifest-bound publication capture paths. Every
raw payload and every source report is checked against its captured digest.
Normalized rows may change only their raw-output path. Original report and
ledger paths remain intact. The 4,252-row, 92-partition, 1,108-ID matrix is
fixed; profiles, calibration and smoke duplication retain their boundaries.

## Freeze and generated figures

Start from a clean checkout of merged main after the input PR. Verify the
retained harness against its release-build digest and all source inputs, or
build the same source on CI. Run `validate` and `validate-reports`, then
`create-freeze --population v0.9.0 --scope release --release v0.9.2` with every
manifest-listed publication report. The recorded benchmark revision must be
the surviving merged-main evidence commit.

Commit the freeze before validation that requires a tag.
`scripts/check-release-v092-results.py` validates in an independent checkout,
hydrates and verifies the portable evidence, and uses a temporary v0.9.2 tag
only inside that checkout before the real tag exists. Generate results there
for the freeze PR, then require the check-only generation pass. Do not push a
pre-validation tag or combine the input and freeze PRs.

Archive the previous generated v0.9.0 model without modifying its bytes. The
new current website reads only the generated v0.9.2 model. Historical latency
remains attached to its historical pins; this release has no current
uncontended timing or relative-performance claim.

## Publication

After the freeze/generated-results PR merges and exact merged-head CI passes,
validate that commit again, create the v0.9.2 tag at that commit and publish
the canonical `docs/releases/v0.9.2.md` notes. Dispatch the manual Pages workflow
from the validated main revision and verify terminal deployment plus the live
version and a raw-evidence link. Publication and deployment are distinct
terminal states. Never overwrite a published freeze, evidence or release tag.

## Known limitations

The release notes and case-variation audit retain all analyzer outcome changes,
including harness errors, incomplete proofs and unsupported profiles. Bifrost
full-policy qualification remains false. Joern current108 remains semantic-only
and untimed; raw reached/not-reached fields do not override normalized
inconclusive outcomes. CodeQL native query-pack lookup errors remain runner
errors, not analyzer accuracy results. Portable result hydration does not
establish portable replay of original CodeQL controls whose frozen verifier
requires the capture host.
