# Publishing the accepted diagnostic timing results

This separately versioned publication implements David's request to publish the
accepted timing results and update the aggregated website overview. No analyzer
or timing campaign is launched. CodeQL Swift recovery and execution remain paused.
The release commit stays `86092336d8f9ca32fe9e2c4042c2dced76c1feb1`.

The new portable publication is
`reports/timing/v0.9.2/publication-20261123-01/`. It retains source hashes and
acceptance receipts. The overview shows all eight analyzer families using their
own retained per-case observations. It never pools case medians, treats an
unsupported case as a zero-time analysis, includes quarantined Rust costs in an
accepted distribution, or interprets incomplete invocation costs as successful
analysis latency. Warm batches and invocation-overhead estimates remain separate.

The A37 reconciliation accepts the retained Joern Swift diagnostic costs after
exact decline-wording reconciliation. It leaves the original failed controller,
96 inconclusive outcomes, four partial invocations, retrospective limitations,
and false timing qualification flags intact. Acceptance for descriptive
publication does not grant settled-timing certification or full-model qualification.

The versioned page is `/snapshots/v0-9-2/timing-20261123-v1/`; the homepage
`#latency` section uses the same all-eight model. Downloads are staged below
`/evidence/timing/v0-9-2/20261123-v1/`. The original 13 November page, data and
downloads keep their original identities.
