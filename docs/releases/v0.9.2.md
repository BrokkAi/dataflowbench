## Honest negatives

- **Bifrost:** versus the published v0.9.0 freeze, four distinct assertions became correct: Go nested-access-path positive and negative, C# recursive-heap-unwind positive, and Rust result-error-propagation negative. C# recursive-heap-unwind negative became a known false positive. Rust dispatch-table negative remains inconclusive with `partial_discovery`. Three JavaScript policy controls remain inconclusive, the three native groups have an empty catalog and 36 unsupported rows, and full policy qualification remains false. The 1,116 Bifrost rows include 116 Smoke repeats; they do not create additional distinct improvements.
- **CodeQL:** 36 new native-profile runner errors (12 each for Java, JavaScript and Python) remain because the pinned query-pack suite lookup could not find its `*-security-extended.qls` suite. Together with the separate earlier Swift runner error, the matrix has 37 CodeQL runner errors in total. These are query-pack availability failures, not analyzer negatives. The paired comparison also has one formerly decisive row now inconclusive, three new wrong decisive answers and one newly correct answer. Version and configuration differences prevent causal attribution.
- **Joern:** 62 Rust-core rows that were decisive at v0.9.0 are now inconclusive (31 positive and 31 negative). The final 108 Swift rows are 96 inconclusive and 12 unsupported; aggregate-resource qualification is unavailable, evidence is semantic-only, scoring is disabled, and timing is not certified.
- **Other paired rows:** FlowDroid, Infer, OpenTaint, Pysa and Semgrep outcomes are unchanged. Unsupported and inconclusive states remain explicit and are not clean negatives.
- **Configuration and performance:** the final canonical validator checked 92 reports; 76 configuration hashes were derivable, 16 were not derivable, and none was KnownStale. This validates report/configuration evidence, not complete semantic qualification. Raw durations remain retained, without a certified current timing comparison; no timing or relative-performance claim is made. Reports and versions differ from the baseline, so the paired variation shows changes, not cause.

## Publisher compatibility changes

These delivery and website changes are separate from analyzer outcomes:

- The current results reader preserves all 119 source-bound configuration references and the historical fixture mapping, with JSON-module imports usable from both Astro and the Node evidence-binding checks. These are reader/test compatibility changes; they do not change analyzer inputs or outcomes.
- The results UI renders execution errors separately from unsupported and inconclusive outcomes. Runner errors do not count as analyzer declines or clean negatives.

- The portable manifest maps 92 normalized reports and 4,252 raw files into the release capture. Normalized report changes are limited to the reversible raw-output path mapping; report outcomes, identities, diagnostics, configuration, and uncertainty remain intact, and raw payload bytes are preserved.
- Five selected Joern Swift reports use the reviewed strict-schema metadata lift. The schema-facing report bodies retain their outcome and diagnostic fields; the qualification/scoring annotations and per-row raw digests remain bound in the required sidecar. Qualification stays unavailable and scoring stays disabled.

## Reproduction

Use a clean checkout of the immutable v0.9.2 tag. Skipping smudge during clone avoids fetching unrelated historical LFS content; the include filter then fetches only this release's portable publication bundle and 151-row ledger archive. Hydration verifies content before restoring paths. The release checker validates that the frozen evidence revision is an ancestor of official main and the release tag, then runs freeze validation and check-only result generation in an isolated checkout. It does not dispatch analyzers.

```sh
GIT_LFS_SKIP_SMUDGE=1 git clone --branch v0.9.2 --single-branch https://github.com/BrokkAi/dataflowbench.git dataflowbench
cd dataflowbench
git lfs install --local --skip-repo
git lfs pull --include='evidence-delivery/v0.9.2-publication-01/detail/**,reports/releases/v0.9.2/ledger-archives/ledger-151-01/ledger-v1.jsonl.gz'
python3 -B scripts/v092_ledger_archive.py hydrate-current --root .
python3 -B scripts/v092_publication_evidence.py hydrate --root .
python3 -B scripts/v092_publication_evidence.py verify --root .
cargo build --release --locked
target/release/dataflowbench validate-freeze reports/freeze.json
target/release/dataflowbench generate-results --manifest reports/freeze.json --output-directory results --check
python3 -B scripts/check-release-v092-results.py \
  --evidence-revision 1ae46241bca35fad8979857f6b46a90535c0de88 \
  --binary "$PWD/target/release/dataflowbench"
```
