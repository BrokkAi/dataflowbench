## Honest negatives

Bifrost's Java anonymous-implementation positive and negative changed from
inconclusive to reached and not-reached respectively. OpenTaint's Java
callback-registration and map-iteration positives changed from not-reached to
reached. All other normalized outcomes equal published v0.7.0.

Bifrost's 36 native unsupported outcomes rest on the exact shipped catalog
and selector mismatch. Its separate positive control remained
inconclusive/partial_discovery with zero endpoints. It proves neither a clean
negative nor successful native activation. OpenTaint's native fixtures meet a
source-selector barrier in the shipped servlet/Spring command-injection rule;
downstream propagator, sanitizer, summary and persistence semantics remain
unresolved behind that barrier. The separate servlet positive activated the
shipped rule; its constant negative did not. Those contended functional probe
durations are excluded from every latency claim.

Desktop activity and uncontrolled OS caches are recorded. Initial Bifrost
runs used sandbox context; five approved full populations were repeated with
elevated access and retained outcome equality, not timing parity. The paired
access control covers only two cases, in fixed order, and supports no
whole-population or timing-parity inference. No blanket uncontended-host
claim or causal cross-release speedup claim is made.

## Reproduction

From the final published tag, run:

```bash
git checkout v0.7.1
cargo run -- validate
cargo run -- --population v0.7.0 validate-reports
cargo run -- validate-freeze reports/freeze.json
cargo run -- generate-results --manifest reports/freeze.json --output-directory results --check
```

Exact measurement argument vectors, identities, attempts and machine conditions
are in the retained ledger. Re-execution creates new evidence; it does not
rewrite this release.

## Immutability

This freeze and its evidence are never rewritten in place. Corrections require
a new release with new digests. Historical published snapshots retain their
original bytes and manifest-containing references.
