# DataFlowBench v0.7.0

The currency release. Every analyzer pin the 2026-09-03 survey found behind
upstream is bumped and its evidence re-run, and the two amendments recorded
since v0.6.1 — the CodeQL endpoint probe and the Bifrost sink-anchor
reconciliation — are bound by a freeze for the first time. The exam did not
change: the same 852 cases at the same fixture revision, re-sat by five of the
eight candidates. Of 3,480 scored case results, twelve moved.

## Honest negatives

Twelve of 3,480 scored case results moved from what v0.6.1 bound. Four moved
because an engine got better; eight moved because this benchmark stopped
crediting a negative it could not prove. Nothing moved into a false positive
or a false negative.

**Four cells decided that were previously undecided.** The Bifrost Go
array-element pair and the PHP map-iteration pair each go from `inconclusive`
to `reached` on the positive and `not-reached` on the negative. The Go pair is
the regression BrokkAi/bifrost-dev #2831 opened against v0.10.8 and v0.10.9
closes; the PHP pair had been reported as an unproven value-flow snapshot. Net
across the thirteen Bifrost kernels: +2 `reached`, +2 `not-reached`, −4
`inconclusive`.

**Five CodeQL clean negatives were withdrawn as vacuous.** Under the endpoint
probe (Amendment A30), the infeasible-branch negative moves from `not-reached`
to `inconclusive` for Python, C#, C, C++, and Ruby. Each of those extractors
prunes the constant-false branch from the control-flow graph, so the source
call never exists as a data-flow node: the retained SARIF shows the sink
observed and the source absent. The negative was true only in the sense that
nothing was found, which is precisely what the probe was preregistered to
catch. Java, Kotlin, Go, Rust and the two ECMA extractors keep the dead branch
as a node, observe both endpoints, and keep their `not-reached`. Whether a
constant-branch prune should count as a decided negative for a template whose
question *is* infeasibility is a contract question A30 leaves open; until it is
answered these five sit outside the decisive denominators rather than being
credited either way.

**Three Bifrost modeling negatives were withdrawn for the same reason.** The
`model-declared-source-negative` case goes from `not-reached` to `inconclusive`
in the Java, JavaScript, and Python modeling populations, under an unchanged
diagnostic reporting that the policy bound no endpoint. This is neither a bump
effect nor a reconciliation effect: the evidence always said the selection was
empty, and the normalizer now reads what it says.

**The three pin bumps moved nothing.** Semgrep CE 1.176.0, Joern 4.0.617 and
OpenTaint `analyzer/2026.09.03.9752bd2` were re-run across all thirty-three of
their slices and reproduced every committed outcome exactly. That is the
result the re-run was there to establish, and it is worth stating plainly:
three engines moved a version and none of them moved a number.

**One upstream signature persists.** The `index_memory` unsupported signature
of #2831 does not disappear with the fix; it moves from the Go array-element
pair, now decided, to the Go map-iteration pair, which was and remains
`inconclusive`. No outcome turns on it, so it is published here as a candidate
for an upstream report rather than held against the pin.

## Everything else, unchanged

The 852 cases, their fixture revision, the four score tiers, the two model
profiles, and the scoring contract are identical to v0.6.1. The eighteen
carried-over reports keep the digests v0.6.1 bound. No template was renamed,
split, merged, or dropped, and no denominator moved.

The runner was restructured during this cycle — `src/main.rs` became a command
surface over one module per analyzer, with the adapter contract extracted into
`src/adapters/mod.rs` (#148, issue #130) — and that change is invisible here by
construction: it produced no new evidence, and `generate-results --check`
proved the published artifacts byte-identical across it.

## Amendments first bound by a freeze here

Two amendments landed on `main` after v0.6.1 was published, and this is the
first freeze to bind the evidence they govern:

- **A30** (2026-09-03) — the eleven CodeQL kernel populations are re-run with
  an endpoint probe evaluated beside the kernel query, so a zero-result SARIF
  can no longer be read as a decided negative unless the retained evidence
  shows both endpoints observed.
- **A31** (2026-09-04) — the twenty Bifrost populations are re-run on v0.10.9,
  and every `reached` outcome is anchor-proven under sink-anchor
  reconciliation.

Amendments A1 through A29 remain in force and are unaffected. The three pin
bumps of this cycle recorded no amendment: they moved declarations and
re-ran evidence under the pin-currency policy, which is not a change to a
preregistered decision.

## Reproduction

```bash
git checkout v0.7.0                # frozen benchmark revision (evidence commit)
# then check out the commit carrying reports/freeze.json for this release
cargo run -- validate
cargo run -- validate-reports
cargo run -- validate-freeze reports/freeze.json
cargo run -- generate-results --manifest reports/freeze.json --output-directory results --check
```

Re-executing the five adapters this release re-ran — which produces new
evidence, and therefore a new freeze, not this one:

```bash
# Bifrost, on v0.10.9
for kernel in c cpp csharp go java javascript kotlin php python ruby rust scala typescript; do
  cargo run -- run-bifrost-$kernel-kernel --bifrost <bifrost-binary>
done
cargo run -- run-bifrost-smoke --bifrost <bifrost-binary>
for language in java javascript python; do
  cargo run -- run-bifrost-$language-modeling --bifrost <bifrost-binary>
  cargo run -- run-bifrost-$language-native --bifrost <bifrost-binary>
done
```

The CodeQL, Joern, Semgrep, and OpenTaint invocations are unchanged from
v0.6.0's; see [`docs/releases/v0.6.0.md`](v0.6.0.md#reproduction). The pinned
artifacts differ: Joern 4.0.617, Semgrep CE 1.176.0, and the OpenTaint
`analyzer/2026.09.03.9752bd2` release assets, whose digests each runner
witnesses before analyzing any case.

release name and digests; the v0.1.0 through v0.6.1 manifests and evidence
remain available at their release commits for audit, including v0.6.1's
account of the Bifrost fix cycle and the outcomes A30 and A31 supersede. This
release has no DOI and no external review claim.
