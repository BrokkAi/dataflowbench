# DataFlowBench v0.8.0

The first freeze of the expanded recursive-composition kernels. The release
grows the corpus from 852 to 1,000 cases and freshly reruns all 82 reports,
producing 4,036 normalized results with no runner-error outcomes.

## Freeze identity

- Evidence revision: `80d4f01bb189d530849f9ceb5d775680fcedfb52`.
- Release tag: `v0.8.0`, to contain this manifest and its generated artifacts.
- Manifest: `reports/freeze.json`; SHA-256 `582b2589648772926bc7da0a83844eed0450f015c3593fa5f2937c10669f4259`.
- Fixture revision: `sha256:4b62280924ed2e141dc8bb8e7b1bddfbd512d0201a3fa82f7b92b223eefca8c9`.
- 1,000 cases, 82 reports, 4,036 results; case schema v2, result schema v1.
- Published comparison: v0.7.1 at `ec9bf68a5aa55286c1876f35ce20059e7371540b`.

## What re-ran

Every normalized report is new; none carried over. The final result set contains
1,239 reached, 1,388 not-reached, 530 inconclusive, 879 unsupported, and zero
runner-error outcomes. All 3,157 invoked cases retain fresh cold timing
sidecars; unsupported cells have no invented timing. Failed and superseded
attempts remain in the 127-row execution ledger and attempt archive.

Joern Java batches 1, 2, 4, 8, and 16 and Semgrep Java batches 1, 2, 4, 8,
and 12 were each repeated twice. Nine invocation-overhead groups were each
repeated three times in recorded quiet-host windows. OS cache state remained
uncontrolled, so these measurements characterize the observed host rather
than proving causal cross-release speedups.

## Honest negatives

The expanded population adds 556 report cells. Among the 3,480 cells shared
with v0.7.1, 124 outcomes changed. CodeQL 2.27.0 records 104 C/C++ cells as
inconclusive where v0.7.1 was decisive; the release keeps those incomplete
results and does not reinterpret them as clean negatives. Bifrost 0.11.4 makes
20 C#, JavaScript, TypeScript, and Ruby cells decisive that were previously
inconclusive.

Native `unsupported` outcomes remain capability decisions. The reviewed issue
#20 R2 packet is a separate evidence lifecycle; this release does not claim
that its real-project analyzers have executed without actual R2 outputs.

this freeze, together with the recursive-composition kernel contracts for the
v0.8.0 population. Real-project preregistration A33 is retained as protocol
only and is not represented as completed execution.

## Reproduction

From the final published tag, run:

```bash
git checkout v0.8.0
cargo run -- validate
cargo run -- validate-reports
cargo run -- validate-freeze reports/freeze.json
cargo run -- generate-results --manifest reports/freeze.json --output-directory results --check
```

Exact argument vectors, identities, failed and superseded attempts, and host
conditions remain in `reports/releases/v0.8.0/ledger.jsonl` and its attempt
archive. Re-execution creates new evidence; it does not rewrite this release.

## Immutability

This freeze and its evidence are never rewritten in place. Corrections require
a new release with new digests. Historical snapshots retain their original
bytes and manifest references.
